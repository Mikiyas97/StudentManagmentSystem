# School Management System (SMS)

## Architecture & Standards
- **Modular Design:** Each subsystem (Auth, Students, Courses, etc.) has its own dedicated directory under `modules/` with `.h` and `.cpp` files.
- **Data Persistence:** Records are stored in `.txt` files.
- **Compatibility:** Code uses standard C++98/C++03 syntax to ensure compatibility across older compilers (index-based loops, avoiding initializer lists).
